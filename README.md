# ♡ Bestem için doğum günü sitesi

Bu klasör artık fotoğrafları ve kişisel metinleri yerleştirilmiş **hazır sürüm** içerir.

## İçindekiler
- `index.html`
- `style.css`
- `script.js`
- `config.js`
- `photos/` klasörü (fotoğraflar yerleştirilmiş)

## Yayınlama (GitHub Pages)
1. GitHub'da yeni bir repository oluştur. Örn: `bestem-dogum-gunu`.
2. Bu ZIP'in **içindeki dosyaların tamamını** repository köküne yükle.
3. **Settings → Pages → Build and deployment → Deploy from a branch** seç.
4. **Branch: main** ve **Folder: /(root)** seçip kaydet.
5. Birkaç dakika sonra siten şu adrese benzer bir bağlantıda açılır:
   `https://kullaniciadin.github.io/bestem-dogum-gunu/`

## Düzenlemek istersen
- Metinleri `config.js` içinden değiştirebilirsin.
- Fotoğraf eklemek/çıkarmak için `photos` klasörünü ve `config.js` içindeki `photos` listesini düzenleyebilirsin.

## Gizlilik notu
GitHub Pages herkese açıktır. Public repository içindeki fotoğraflar teknik olarak erişilebilir olur. Çok özel fotoğraflar için bunu göz önünde bulundur.
